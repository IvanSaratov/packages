Пакеты IvanSaratov для Fedora

Личный репозиторий подписанных RPM. Поддерживается Fedora 44 x86_64.

Подключение

Скачайте файл репозитория, проверьте его содержимое и установите:

curl -fsSLO https://ivansaratov.github.io/packages/ivansaratov-fedora.repo
cat ivansaratov-fedora.repo
sudo install -m 0644 ivansaratov-fedora.repo /etc/yum.repos.d/ivansaratov-fedora.repo
sudo dnf install finances

При первом импорте ключа сверьте его отпечаток:

596868911C1A853E42B542B6E9FDF6D61C3EE740

Открытый ключ подписи Finances.

Обновление

sudo dnf upgrade

Установка и обновление пакетов выполняются через DNF без GitHub-токена. Настройка базы данных и запуск приложения выполняются отдельно.

Проверка пакетов

Для RPM включена проверка подписи: gpgcheck=1. Метаданные передаются по HTTPS и не имеют отдельной GPG-подписи: repo_gpgcheck=0.
